## Developer Friendly

Built with modern technologies for easy integration.

```typescript
// Example API Integration
import { createInvoice } from "@acme/sdk";

async function main() {
  const invoice = await createInvoice({
    amount: 5000,
    currency: "USD",
    customer: "cus_123456",
  });

  console.log("Invoice created:", invoice.id);
}
```
